# Profile (example)

translate.py sends this file to Gemini on every run that has changes to
judge. It is what turns "the page changed" into "ignore this" or "apply
today." Copy it to `profile.md` and replace the placeholders with your own.
If `profile.md` does not exist, this example is used as-is.

## Who this is for

[YOUR NAME], a [YEAR, e.g. sophomore] at [SCHOOL], graduating [MONTH YEAR].
Work authorization: [e.g. US citizen, no sponsorship needed].

Recruiting for [e.g. US consulting and finance internships]. Target firms:
[e.g. McKinsey, Bain, BCG, Goldman Sachs, JPMorgan]. Eligible for
[e.g. sophomore and early-identification programs], not for
[e.g. junior-only or full-time analyst roles].

## What counts as a meaningful change

- A relevant program opening applications, posting a deadline, or changing
  eligibility.
- Anything that changes what this person should do this week.

## What does NOT count

- Roles outside [YOUR LOCATION/COUNTRY].
- Roles meant for a different graduating class or seniority.
- Layout, wording, or cosmetic changes that do not change what is offered.
